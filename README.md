# LearnX Premium Learning OS — V9

V9 focuses on a smooth mobile-first learning experience:

- Exact user-provided fingerprint screen reference is used for the access gate.
- Intro audio/video is isolated from dashboard audio.
- Dashboard greeting plays first; anime dashboard video stays paused until the greeting has finished and the video is ready.
- Dashboard video is lightweight H.264/AAC for smoother mobile playback.
- Continuous ivory dashboard surface prevents black seams while scrolling.
- All curriculum lessons open into a dedicated LearnX Study Room styled like a digital textbook.
- Study Room includes Book, Example, Active Practice, Summary, navigation, and a learning-method coach.
- Curriculum study rooms are generated for every subject and every listed lesson.
- Icons use a consistent floating liquid-glass visual language.
- Music Island stays out of the intro and expands at the top when audio is playing.
- Local audio playback has a single reliable play/pause state.
- Q&A and IQ features remain local/offline; IQ is practice reasoning, not a clinical IQ measurement.
